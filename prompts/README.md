# prompts

Copia de los prompts de las tareas programadas. Sirve para que no se pierdan y para proponer cambios con el texto exacto.

- El prompt de una tarea programada solo se puede cambiar desde la sesión donde corre: lo aplica el agente dueño, con OK de Agustín en su chat.
- Cada archivo dice si es la versión vigente o una propuesta pendiente de aplicar.
