Fuente única de reglas y decisiones de todos los agentes de Claude. Cualquier agente, sesión o chat arranca leyendo `REGLAS_VIGENTES.md`.

| Archivo | Para qué |
|---|---|
| [REGLAS_VIGENTES.md](REGLAS_VIGENTES.md) | Lo que rige hoy, máximo 2 páginas. Siempre se lee. |
| [DECISIONES.md](DECISIONES.md) | Registro de solo agregar: fecha, agente, decisión, motivo, quién la pidió. |
| [AGENTES.md](AGENTES.md) | Cada agente: qué hace, dónde corre, tareas programadas, permisos. |
| [PERSONAS.md](PERSONAS.md) | Equipo, proveedores, clientes y cómo los trata Agustín. |
| [SISTEMA.md](SISTEMA.md) | Herramientas, IDs técnicos, horarios y vencimientos. |
| [dominios/](dominios/) | Reglas propias de cada agente. |
| [ARCHIVO/](ARCHIVO/) | Lo que ya no rige. |
| [respaldos/](respaldos/) | Copias de código que vive fuera de un repo (script del briefing). |

Mantiene: ORQ. Para cambiar una regla, pedíselo a ORQ o dejá una entrada en `DECISIONES.md`.
